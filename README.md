# Росгвардия · Морская тема (фан-сайт)

Демонстрационный сайт в военно-морской тематике Росгвардии по мотивам rosguard.gov.ru.

## Структура
- `index.html`   — главная: герой-секция с анимированным морем, стреляющими кораблями, сводкой новостей, счётчиками и бегущей строкой.
- `brigade.html` — страница про Отдельную бригаду особого назначения Росгвардии в Крыму (в/ч 6939): статья, галерея, сайдбар и раздел с описанием геральдического знака — эмблемы вч 6939 (утверждена приказом Росгвардии от 15.10.2020 № 404).
- `css/style.css` — стили: крапово-золотая палитра, 4 слоя анимированных SVG-волн, прибоя, карточки, адаптив.
- `js/sea.js`     — canvas-анимация: 5 слоёв волн (Фурье-ряды), мерцающие звёзды, 3 боевых корабля с качкой, артиллерийские залпы (вспышки, дым, трассеры, снаряды с баллистикой, всплески), reveal-при-скролле, счётчики, бургер-меню.
- `img/emblem6939.svg` — векторная реконструкция эмблемы вч 6939 (щит, грифон с ключом, мост, синяя оконечность, шашки, лента «ВСЕГДА НА СТРАЖЕ»).
- `img/*.jpg` — загруженные фото-превью из открытых источников (rosguard.gov.ru и др.).

## Запуск
```bash
python3 -m http.server 8080
# открыть http://localhost:8080/index.html
```
